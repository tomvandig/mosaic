# mosaic

Mosaic is a file format for **incremental collaboration on geometric, structured data**. Many data sources may be combined to form a bigger composed picture but in the composition they **retain their identity and lineage**.

[Examples](https://tomvandig.github.io/mosaic/viewer/?example=s1)

Mosaic takes lessons from and addresses shortcomings of modern data patterns from *usd*, *ecs*, *json* and *gltf*, and combines them into a single flexible data system.

Mosaic:
* is unopinionated on your data
* can serialize & validate any data type with JSON schema component schemas
* allows people to collaborate on that data through file exchange or through an API
* takes an ECS approach to decoupling data from usecases
* elevates parent-child relationships to allow for geometric assemby reuse
* supports semantic typing through native inheritance

Please see below for documentation.

## Status

Mosaic is currently in active development, not yet ready for production use.
